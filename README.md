# Abobakr Khaled — Portfolio

A modern, animated personal portfolio built with plain **HTML, CSS and JavaScript**. No frameworks, no build step.

## ✨ Features

- **Animated hero**: a typing effect that cycles through roles, and a 3D-tilting code card with floating badges
- **Interactive background**: a particle network that reacts to the mouse, plus a glow that follows the cursor
- **Scroll animations**: sections fade in, stat numbers count up, skill bars fill in, and a progress bar tracks reading position
- **Project showcase**: filter by *Websites* / *Applications*, tilt cards, and Live Demo / Code links
- **Live mini demos**: a working one-line calculator and counter inside their project cards
- **Contact form**: sends the visitor's message straight to WhatsApp
- **Responsive**: adapts from desktop to phone, with a full-screen mobile menu
- **Accessible motion**: animations turn off for visitors who have *reduce motion* enabled

## 🛠️ Built With

- HTML5
- CSS3 (custom properties, grid, flexbox, keyframe animations, `backdrop-filter`)
- Vanilla JavaScript (`IntersectionObserver`, Canvas API)
- Fonts: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) and [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)

## 📁 Project Structure

```
portfolio/
├── index.html    # Page content and sections
├── style.css     # Styles, animations and responsive layout
├── script.js     # Interactions, effects and mini demos
└── favicon.svg   # <AK/> tab icon
```

## 🚀 Run Locally

Open `index.html` in any browser, or serve the folder with a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
